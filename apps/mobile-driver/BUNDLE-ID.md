# PERINGATAN — bundle ID belum final

`app.json` masih memakai placeholder:

```
id.co.GANTI-BADANHUKUM.pesona.driver
```

**Bundle ID tidak dapat diubah setelah aplikasi terbit di Play Store atau App Store.**
Mengubahnya berarti aplikasi baru: kehilangan seluruh basis pengguna, rating, dan riwayat instalasi.

Ganti `GANTI-BADANHUKUM` dengan domain badan hukum koperasi sebelum build rilis pertama.
Sampai itu dilakukan, jangan pernah menjalankan submit ke store.
